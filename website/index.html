Let your AI use your computer.

M-Cowork is a desktop app that lets people use their AI like OpenCode. It sees the screen, moves the mouse and types on the keyboard.

FEATURES

Everything in the box.

A desktop agent, not a browser tab. The UI, the model and the automation engine are separate pieces that talk over a small, documented protocol.

Sees the screen

Screenshots are fed back to the model as real images, so it reasons about what is actually on your desktop.

Real mouse & keyboard

Smooth cursor movement, clicks, drags, scrolling, typed text and shortcuts — through Win32 or X11.

Seven providers

Gemini, OpenAI, Anthropic, DeepSeek, OpenRouter, Groq and local Ollama. Bring a key or run it offline.

Human in the loop

An optional Allow / Deny prompt before every OS action, plus Esc to abort a run at any moment.

Local-first state

Sessions, settings and keys live on this machine. Nothing is proxied through an M-Cowork server.

Persistent sessions

Search, rename, archive, restore and permanently delete chats. Each session keeps its own model.

Voice input

Record from the mic and transcribe with Whisper through Groq or OpenAI, then edit before sending.

Readable output

Markdown responses, reasoning cards, live tool status badges and one-click retry on errors.

MODELS

Bring your own model.

Pick a provider in the settings panel, add your key, model and a custom base URL. Everything is stored locally.

FAQ

Questions, answered.

Does it run shell commands or touch my files?

No. On main the engine exposes only the ten GUI tools above. Filesystem, shell, SSH/SFTP and git tools are planned and will be opt-in and gated separately.

Do I need an API key?

For hosted providers, yes — add one per provider in Settings. Ollama runs locally and needs no key. Google Gemini can also sign in through Antigravity OAuth.

Where is my data stored?

Sessions and settings stay on this machine under the app data folder. Chat content is sent only to the provider you selected. Keys are stored locally.

Can I stop it mid-task?

Yes. Press Esc in the app, or hit the red Stop button, and the engine ends the session and returns cursor control to you.

Which platforms are supported?

Windows 10/11 and Linux (X11; Wayland with grim or ImageMagick import). macOS is not implemented yet.

Is it open source?

The source is on GitHub. Build it yourself with the steps above, or browse the code to see exactly what the agent can do.
